# 손수재미

고정 5명이 함께 쓰는 1박 2일 여행 관리 웹입니다.  
가능한 날을 맞추고, 여행을 계획하고, 다녀온 뒤 기록과 후기를 남깁니다.

## 서비스 주소

Vercel에 배포하고, 가비아에서 구매한 도메인을 연결해 사용합니다.

주소는 **https://www.ssjm.site/** 입니다.

## 화면

- **일정 조율** — 함께 갈 수 있는 날을 확인합니다.
- **여행** — 확정된 여행의 숙소, 식사, 놀거리를 정리합니다.
- **기록** — 다녀온 여행과 장소를 모아 보고, 후기를 남깁니다.

로그인한 멤버만 이용할 수 있습니다. 회원가입은 없고, 정해진 계정으로 로그인합니다.

## 기술 스택

- React 19
- Vite
- React Router
- Zustand
- Tailwind CSS 4
- Axios

## 로컬 실행

```bash
npm install
copy .env.example .env
npm run dev
```

개발 서버는 기본적으로 `http://localhost:5173` 에서 열립니다.
